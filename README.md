# KoaZa Foreseer — کوازا آینده‌نگر

نسخهٔ اولیهٔ قابل توسعه از برنامهٔ دسکتاپ تحلیل و احتمال فوتبال برای ویندوز. رابط کاربری فارسی و راست‌به‌چپ است.

> وضعیت انتشار: **Source preview / 0.1.0**. این بسته شامل سورس پروژه است، نه فایل اجرایی کامپایل‌شده. محیط ساخت فعلی فاقد .NET SDK ویندوز/WPF است؛ پروژه باید روی ویندوز با .NET 8 SDK ساخته و آزموده شود.

## امکانات موجود

- رابط WPF فارسی با فهرست رقابت‌ها، فهرست مسابقات و پنل احتمال‌ها.
- اتصال اختیاری به API-Football از طریق کلید شخصی کاربر.
- کشف کاتالوگ رقابت‌های گزارش‌شده از API-Football و کشف رقابت‌های موجود در OpenLigaDB.
- دریافت مسابقات آینده در بازهٔ ۷ روزه، تاریخچهٔ اخیر برای مدل و فید زنده از API-Football.
- دریافت مسابقات لیگ‌های انتخاب‌شدهٔ OpenLigaDB.
- ذخیرهٔ تنظیمات در `%LOCALAPPDATA%\KoaZa\Foreseer\settings.json` و داده‌ها در SQLite محلی.
- تازه‌سازی خودکار هر ۲۰ دقیقه و کنترل فاصلهٔ درخواست‌ها برای جلوگیری از مصرف بی‌رویهٔ سهمیه.
- مدل پایهٔ پواسون برای 1X2، بالای ۲٫۵ گل و گل‌زنی هر دو تیم؛ در صورت کمبود تاریخچه، از ساختن احتمال خودداری می‌کند.
- شناسهٔ داخلی جداگانه برای هر منبع و ذخیرهٔ شناسهٔ ارائه‌دهنده.

## نیازمندی‌ها

- Windows 10/11
- .NET 8 SDK
- اتصال اینترنت برای دریافت داده از ارائه‌دهنده‌ها
- کلید API-Football برای کاتالوگ گسترده و فید زنده؛ OpenLigaDB بدون کلید در دسترس است.

## اجرای توسعه‌ای

در PowerShell، از پوشهٔ پروژه:

```powershell
dotnet restore
dotnet build -c Release
dotnet run -c Release
```

یا `build.ps1` را اجرا کنید. برای ساخت فایل اجرایی self-contained (برای معماری x64):

```powershell
dotnet publish .\KoaZa.Foreseer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\publish\win-x64
```

## تنظیم API-Football

1. از [وب‌سایت رسمی API-Football](https://www.api-football.com/) حساب بسازید و کلید خود را بگیرید.
2. برنامه را باز کنید و کلید را در قسمت اتصال وارد کنید.
3. «ذخیرهٔ تنظیمات» را بزنید و سپس «تازه‌سازی داده‌ها» را انتخاب کنید.
4. رقابت‌های موردنیاز را در ستون سمت راست/فهرست رقابت‌ها فعال کنید و تنظیمات را ذخیره کنید.

کلید در مخزن یا فایل نمونه قرار داده نشده است. در این نسخه کلید به‌صورت متن محلی در فایل تنظیمات ذخیره می‌شود؛ رایانهٔ شخصی و فایل تنظیمات را ایمن نگه دارید. نسخهٔ بعدی بهتر است از Windows Credential Manager استفاده کند.

## سهمیه و رفتار به‌روزرسانی

یک تازه‌سازی موفق با API-Football حداکثر سه درخواست انجام می‌دهد: کاتالوگ رقابت‌ها، بازهٔ تاریخی/آینده و فید زنده. تنظیم پیش‌فرض تازه‌سازی خودکار ۲۰ دقیقه است؛ کاتالوگ حداکثر روزی یک‌بار و تاریخچه/برنامه حداکثر هر ۶ ساعت درخواست می‌شود. سهمیهٔ واقعی به حساب و طرح ارائه‌دهنده بستگی دارد؛ برنامه نباید به‌عنوان تضمین‌کنندهٔ نرخ به‌روزرسانی زنده تلقی شود.

## محدودیت‌های شناخته‌شدهٔ نسخهٔ 0.1.0

- هنوز در این محیط کامپایل یا اجرای WPF انجام نشده است؛ پس از انتقال به ویندوز، build و تست دستی لازم است.
- پوشش آمار زنده، کرنر، کارت، شوت، ترکیب و ضرایب به دادهٔ موجود برای هر رقابت و مجوز پلن API وابسته است. این نسخه فعلاً آن بازارها را محاسبه نمی‌کند.
- مدل احتمال از میانگین گل‌های مسابقات کامل ذخیره‌شده استفاده می‌کند؛ مدل ابتدایی است و هنوز تعدیل قدرت حریف، میزبانی دقیق، مصدومیت، ترکیب، کالیبراسیون یا اعتبارسنجی زمانی ندارد.
- تاریخچهٔ ۶۰ روز اخیر با یک درخواست بازه‌ای دریافت می‌شود؛ اگر پاسخ ارائه‌دهنده محدود باشد یا برخی رقابت‌ها در پاسخ نیایند، مدل دادهٔ کافی نخواهد داشت.
- اتصال OpenLigaDB از کاتالوگ عمومی آن استفاده می‌کند؛ داده‌های آن لزوماً دارای کشور، آمار پیشرفته یا پوشش کامل همهٔ رقابت‌ها نیست.
- تطبیق هوشمند یک رقابت بین چند ارائه‌دهنده و رفع ابهام نام‌ها هنوز کامل نیست؛ مسابقات از طریق شناسهٔ منبع ذخیره می‌شوند تا از ادغام اشتباه جلوگیری شود.
- تنظیمات منبع‌ها در نسخهٔ فعلی محدود است و تنظیم فاصلهٔ تازه‌سازی از مدل پیش‌فرض می‌آید.

## ساختار پوشه‌ها

- `Models/`: مدل‌های دامنه و تنظیمات
- `Services/`: ارائه‌دهندگان داده، SQLite، تنظیمات و مدل احتمال
- `ViewModels/`: state و فرمان‌های رابط
- `MainWindow.xaml`: رابط WPF
